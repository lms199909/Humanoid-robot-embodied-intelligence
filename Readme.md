# 人形机器人具身智能系统项目架构设计文档


## 一、项目概述与范围

### 1.1 项目背景

本项目基于逐际动力（LimX Dynamics）全尺寸通用人形机器人 **LimX Oli** 平台，构建面向**工业场景**（搬运装配）与**科研验证**（斜梯攀爬等复杂地形通过）的具身智能系统。项目采用**混合式架构**（大模型慢思考 + MPC/RL快思考），核心算力机载部署，大模型推理依赖外部服务器。

### 1.2 核心目标

| 目标编号 | 目标描述 | 验收标准 |
|:---|:---|:---|
| G1 | 在仿真环境中实现Oli机器人的斜梯攀爬 | 成功通过≥30°斜梯，无摔倒 |
| G2 | 在仿真环境中实现工业搬运/装配任务 | 成功抓取目标物体并完成放置/装配 |
| G3 | 建立完整的感知-决策-执行闭环 | 端到端任务成功率≥70%（仿真） |
| G4 | 验证混合式架构的可行性 | 大模型任务分解正确率≥80% |

### 1.3 性能指标

| 指标类别 | 指标名称 | 目标值 |
|:---|:---|:---|
| 实时性 | 控制周期 | ≤ 1ms（1000Hz） |
| 实时性 | 感知-决策延迟 | ≤ 100ms |
| 实时性 | 大模型推理延迟（服务器） | ≤ 2s |
| 成功率 | 斜梯攀爬成功率 | ≥ 70% |
| 成功率 | 抓取装配成功率 | ≥ 70% |
| 资源 | 机载算力利用率 | ≤ 80% |

### 1.4 项目范围

- **包含**：仿真环境搭建、感知系统集成、混合式决策架构开发、运动控制实现、反馈闭环、文档与测试
- **不包含**：真机硬件改造、末端执行器硬件选型（使用Oli标配）、大规模数据采集与模型训练

## 三、感知系统设计

### 3.1 传感器配置

基于LimX Oli的标配传感器：

| 传感器类型 | 型号/规格 | 数量 | 用途 |
|:---|:---|:---|:---|
| 头部深度相机 | Intel RealSense D435i | 1 | 环境感知、物体识别 |
| 胸部深度相机 | Intel RealSense D435i | 1 | 近距离操作、抓取定位 |
| 6轴IMU | 自研（抗干扰） | 1 | 姿态估计、步态稳定 |
| 关节编码器 | 内置 | 31 | 关节角度/速度反馈 |
| 力矩传感器 | 内置 | 若干 | 力控、接触检测 |

**扩展接口**：USB 3.0/3.2、千兆以太网，支持外接激光雷达、触觉传感器等。

### 3.2 感知模块

| 模块名称 | 功能描述 | 输入 | 输出 | 频率 |
|:---|:---|:---|:---|:---|
| 视觉感知 | 目标检测、姿态估计、场景分割 | RGB-D图像 | 物体位姿、语义标签 | 30Hz |
| 本体感知 | 关节状态、IMU融合 | 编码器、IMU | 全身状态向量（33维） | 1000Hz |
| 多模态融合 | 视觉+触觉+力觉融合 | 视觉特征、力/触觉 | 融合感知结果 | 30Hz |

## 十、安全与冗余机制

### 10.1 安全层级

| 层级 | 机制 | 触发条件 | 响应 |
|:---|:---|:---|:---|
| L1 | 关节力矩限幅 | 力矩>150N·m | 限幅输出 |
| L2 | 姿态监测 | 俯仰/横滚角超限 | 步态调整 |
| L3 | 碰撞检测 | 外力/位置偏差 | 停止+回退 |
| L4 | 紧急停止 | 任何严重异常 | 立即停机 |
| L5 | 通信超时 | 服务器无响应>3s | 降级模式 |

### 10.2 降级策略

| 场景 | 降级方案 |
|:---|:---|
| 大模型服务不可用 | 使用预设技能模板，跳过任务分解 |
| 感知失败 | 使用历史场景图，降低速度 |
| 控制异常 | 切换到安全姿态，等待人工介入 |
| 通信中断 | 完成当前技能后停止，上报状态 |
